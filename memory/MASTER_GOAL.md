# Master Goal

Build an autonomous, cloud-first cinematic R&D system that:

- Uses free cloud workers for routine work.
- Uses GPT-6 Astra as a sparse reviewer/corrector.
- Generates video in the cloud, never through local AI inference.
- Can swap video/image/audio providers without redesigning movie logic.
- Learns from experiments through durable project memory.
- Can run manually or on schedules.
- Preserves exact provenance of agent-created work.
- Keeps paid spend disabled unless explicitly approved.
- Audits previous agent-created PC artifacts safely before any cleanup.

Success means the system can research an approach, run a minimal cloud experiment, evaluate it, persist lessons, submit a review packet, apply Astra corrections if rejected, and promote a working provider-independent pipeline after approval.
